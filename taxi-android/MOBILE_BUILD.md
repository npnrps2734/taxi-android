# Сборка Android-приложения

Это нативное Android-приложение (Kotlin) — оболочка, которая открывает ваш
веб-сервис такси в полноэкранном виде, с иконкой на рабочем столе телефона,
доступом к геолокации и без адресной строки браузера. При первом запуске
приложение попросит указать адрес вашего сервера (например,
`https://mytaxi.ru` после того, как вы развернёте бэкенд по инструкции из
DEPLOY.md) — это можно будет изменить позже через меню в приложении.

**Важно:** собрать APK-файл в этой облачной песочнице не получилось —
корпоративная сетевая политика блокирует загрузку Android SDK с серверов
Google (dl.google.com), это не техническая ошибка, а осознанное ограничение
безопасности. Поэтому весь код готов, но собрать из него установочный файл
нужно одним из двух способов ниже — оба бесплатны и не требуют Mac.

## Способ 1 — GitHub Actions (рекомендуется, ничего устанавливать не нужно)

1. Зарегистрируйтесь на https://github.com (бесплатно), если ещё нет аккаунта.
2. Создайте новый репозиторий (можно приватный).
3. Загрузите в него содержимое папки `taxi-android` (через веб-интерфейс
   GitHub — кнопка «Add file» → «Upload files» — или через `git push`, если
   умеете пользоваться git).
4. **Важно:** файл настройки автосборки не удалось положить в папку
   автоматически (защищённый путь `.github`). Создайте его сами — в GitHub
   нажмите «Add file» → «Create new file», в поле имени введите ровно
   `.github/workflows/build-android.yml` (слэши создадут вложенные папки
   автоматически) и вставьте туда содержимое из раздела «Содержимое
   build-android.yml» в конце этого файла. Сохраните (Commit new file).
5. В репозитории откройте вкладку **Actions** — сборка запустится
   автоматически. Если не запустилась сама — нажмите «Run workflow».
5. Когда сборка закончится (обычно 3–5 минут), откройте её результат и
   скачайте файл `taxi-app-debug` — внутри будет `app-debug.apk`.
6. Скопируйте `app-debug.apk` на телефон (через USB, Google Диск, Telegram
   «Избранное» и т.п.) и откройте его — Android спросит разрешение на
   установку из неизвестного источника (это нормально для APK не из Google
   Play), подтвердите.

## Способ 2 — Android Studio на вашем компьютере

1. Скачайте и установите Android Studio: https://developer.android.com/studio
   (бесплатно, ~1 ГБ, работает на Windows).
2. Откройте Android Studio → «Open» → выберите папку `taxi-android`.
3. Android Studio сам предложит скачать недостающие компоненты SDK и создать
   Gradle wrapper — согласитесь на всё.
4. Дождитесь окончания синхронизации проекта (внизу окна).
5. Нажмите зелёный треугольник «Run» (▶) с подключённым по USB телефоном
   (с включённой отладкой по USB) — либо соберите APK через меню
   **Build → Build Bundle(s) / APK(s) → Build APK(s)**, файл появится в
   `app/build/outputs/apk/debug/app-debug.apk`.

## Дальше: iOS

Как договаривались — сборку под iOS я не могу сделать сама (нет своего Mac).
Когда дойдёт очередь до iOS, самый простой вариант — сервис Codemagic
(https://codemagic.io) или Expo EAS Build: они собирают iOS-приложения в
облаке без своего Mac, за это время можно портировать этот же WebView-подход
на iOS (или переписать на React Native — тогда одна кодовая база соберётся
под обе платформы). Скажите, когда будете готовы этим заняться — подготовлю
код и настрою сборку.

## Что можно улучшить потом

- Сейчас это WebView-обёртка над веб-версией — рабочий и быстрый способ
  получить настоящее приложение уже сейчас. Полностью нативный интерфейс
  (более плавный, с нативными картами Яндекс.Карт) можно сделать следующим
  шагом на React Native или Kotlin+Jetpack Compose, когда веб-версия
  стабилизируется.
- Значок приложения сгенерирован программно — при желании закажите
  дизайнеру красивую иконку и просто замените PNG-файлы в папках
  `app/src/main/res/mipmap-*/`.

## Содержимое build-android.yml

Создайте файл `.github/workflows/build-android.yml` с этим содержимым:

```yaml
name: Build Android APK

on:
  push:
    branches: [ main, master ]
  workflow_dispatch: {}

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'

      - name: Set up Android SDK
        uses: android-actions/setup-android@v3

      - name: Set up Gradle
        uses: gradle/actions/setup-gradle@v4

      - name: Build debug APK
        run: gradle assembleDebug

      - name: Upload APK
        uses: actions/upload-artifact@v4
        with:
          name: taxi-app-debug
          path: app/build/outputs/apk/debug/app-debug.apk
```
